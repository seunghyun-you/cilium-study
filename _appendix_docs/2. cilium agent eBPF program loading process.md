### 1.1 /sys/fs/bpf 디렉토리 조회
- /sys/fs/bpf 폴더는 리눅스 커널의 eBPF 파일 시스템(eBPF 프로그램, 맵)이 마운트되는 위치다.
  - devices는 네트워크 인터페이스와 관련된 eBPF 프로그램을 관리한다.
  - endpoints는 각 컨테이너 엔드포인트(Pod)와 관련된 eBPF 프로그램을 관리한다.
  - socketlb는 소켓 로드 밸런싱과 관련된 eBPF 프로그램을 관리한다.
  - tc/globals는 Traffic Control과 관련된 eBPF 맵이 저장되는 곳이다.

### 1.2 Cilium Agent가 eBPF 프로그램을 커널에 로드하는 과정
- cilium agent의 initContainer 부분을 보면 command를 이용해서 호스트 노드의 cgroup에 접근 후 cilium-mount 프로그램을 실행해서 프로그램을 호스트의 커널에 로드한다.
```bash
root@cilium-ctr:~# kubectl get po  $CILIUMPOD1 -n kube-system -oyaml | grep -B5 nsenter
    - command:
      - sh
      - -ec
      - |
        cp /usr/bin/cilium-mount /hostbin/cilium-mount;
        nsenter --cgroup=/hostproc/1/ns/cgroup --mount=/hostproc/1/ns/mnt "${BIN_PATH}/cilium-mount" $CGROUP_ROOT;
```

- cilium agent의 /usr/bin/cilium-mount 위치를 조회하면 실행하는 프로그램이 조회된다.

```bash
root@cilium-ctr:~# kubectl exec -it $CILIUMPOD1 -n kube-system -- ls /usr/bin/cilium-mount
/usr/bin/cilium-mount
```

- initContainer에 할당된 환경 변수들도 cilium agent의 yaml 내부를 보면 확인할 수 있다.
```bash
root@cilium-ctr:~# kubectl get po $CILIUMPOD1 -n kube-system -oyaml | grep -A4 env:
...
    env:
    - name: CGROUP_ROOT
      value: /run/cilium/cgroupv2
    - name: BIN_PATH
      value: /opt/cni/bin
...
```

- 파라미터로 전달되는 /run/cilium/cgroupv2 를 cilium agent에서 조회하면 다음과 같다.
```bash
root@cilium-ctr:~# kubectl exec -it $CILIUMPOD1 -n kube-system -- ls /run/cilium/cgroupv2
cgroup.controllers      cgroup.pressure  cgroup.subtree_control  cpu.stat               cpuset.cpus.isolated   dev-mqueue.mount  io.cost.qos    io.stat           memory.pressure  memory.zswap.writeback  proc-sys-fs-binfmt_misc.mount  sys-kernel-debug.mount    user.slice
cgroup.max.depth        cgroup.procs     cgroup.threads          cpu.stat.local         cpuset.mems.effective  init.scope        io.pressure    kubepods.slice    memory.reclaim   misc.capacity           sys-fs-fuse-connections.mount  sys-kernel-tracing.mount
```

- 결국 command 내용이 하는 역할을 보면 nsenter를 이용해 호스트 네임스페이스에 접근 후 네트워크 정책을 적용하고 관리하는데 필요한 cgroup 파일 시스템들을 호스트에 설정하는 것이다.
